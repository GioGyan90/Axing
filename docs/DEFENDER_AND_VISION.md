# 困难模式后卫与裁判视野

2026-11-10，接在 `57f5621` 的动作优化之后。

## 裁判

“缩小 2/3”按视野距离处理：半径 **7.5 → 2.5**，半角仍为 55°。绿色扇形和真实犯规检测共用 `config.js / REFEREE_VISION`，删除两份重复检测，避免只缩小画面而判罚仍覆盖原范围。玩家距裁判 3.0 时不再进入视野，距 2.0 且处于扇形内时仍会被判犯规。

## 后卫

难度值 1 / 2 / 3 保留，界面标为简单、普通、困难。**仅困难（等级 3）启用一名后卫**：橙色球衣、深色短裤、4 号，复用原游戏身体与现有人头素材，不替换主角或门将。切换回较低难度即隐藏并取消未完成的抢断；切回困难仍复用同一人物。

- 开局从 `(2.3, 0, -0.2)` 出发，1.2 秒准备期后主动追球，略微预判滚动方向。
- 移速 5.1，低于主角普通跑动 6.1；玩家可以变向或加速摆脱。身体保持与主角至少约 0.65 的间距，并受球场边界约束。
- 靠近低球后播放上一轮由 3D_AItool 烘焙的出脚片段，接触阶段校正脚部。足球与球鞋相对运动的扫掠距离确认触球后，才向旁侧拨球。
- 成功抢断解除主角带球、打断尚未触球的蓄力 / 出脚，并短暂阻止立即吸回足球。玩家可追上重新夺球；**抢断本身不消耗进攻机会**，原有进球、出界、门将扑救和犯规计分保留。
- 每次出脚后有冷却；高球、已经躲开的球不会被远距离吸走。重开恢复初始位置和准备期，比赛结束 / 回合重置 / 哨响后停止抢断。

实现：`scripts/game/defender.js`；在 `main.js` 里创建、绑定困难切换并每帧更新，`resetRound` 同步重置。

## 验证

原有 25 项动作检查加 10 项本轮检查，共 **35 项通过**。本轮覆盖：共用视野与实际罚球边界、低难度隐藏、开局保护、难度切换取消出脚、30 / 60 FPS 追球和真实抢断、无额外扣分与可夺回球、高球 / 躲开球无远程抢断、暂停 / 重置取消接触。

`motion-review.html` 的“对抗检查”可测试困难后卫、切换普通后的隐藏、缩小后的裁判扇形。浏览器实际回调抢断成功，普通模式显示 0 名后卫，切回困难显示 1 名；裁判距玩家 3.0 时显示视野外。检查页仅为克服 Canvas 绘图慢而用固定的 1/60 秒游戏步长追上经过的时间，正式游戏仍沿用原来的主循环。

当前环境的视觉验证仍为 Canvas 兼容预览，未进行 WebGL/GPU 或移动端实机验收。
